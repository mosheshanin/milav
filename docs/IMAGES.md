# Картинки слов: как добавить и заменить

Картинку слова можно добавить, не трогая код: положить файл в «ящик» в репозитории. Автоматика (GitHub Actions, workflow «Картинки слов») сама уменьшит файл, положит в приложение, пропишет в уроке и сохранит в `main`; Cloudflare затем выложит новую версию. Если картинки у слова нет, на карточке показывается первая буква слова, так что приложение работает и без них.

## Как положить картинку

1. Подготовьте картинку: квадрат (например 512 на 512), простой плоский рисунок, лучше всего PNG с прозрачным фоном; в приложении она показывается небольшой (до 112 пикселей), мелкие детали не видны. Все картинки лучше делать в одном стиле.
2. Назовите файл **по id слова** (список ниже), расширение `png`, `jpg`, `webp` или `svg`: `home-2-table.png`.
3. Откройте на GitHub репозиторий, папку `content/inbox/images`, нажмите **Add file → Upload files**, перетащите файлы (можно сразу много) и нажмите **Commit changes** (прямо в ветку `main`). Удобнее с компьютера: в мобильной версии GitHub загрузка файлов может быть недоступна.
4. Через 1–2 минуты во вкладке **Actions** появится запуск «Картинки слов». Зелёная галочка: файлы приняты и сохранены (папка `images` опустела), через пару минут их увидят в приложении. Красный крестик: откройте запуск, внизу в аннотациях написано, что не так с каждым файлом (неверное имя, нет такого слова, слишком большой файл). Такие файлы остаются в ящике, исправьте имя или замените файл.

Чтобы **заменить** уже существующую картинку, положите файл с тем же именем: новая заменит старую, а ненужный старый файл удалится.

## Что делает автоматика

- растровые файлы (`png`, `jpg`, `webp`) уменьшаются до 384 пикселей по длинной стороне (меньшие не увеличиваются) и сохраняются как `webp` в `apps/web/public/words/<id>.webp`; `svg` переносится как есть (до 200 КБ);
- в JSON урока у слова пишется `image`; если слово-пример какой-то буквы алфавита то же самое слово, картинка прописывается и ему;
- у слова-примера буквы, которого нет среди слов уроков (например `הר` у буквы ה), файл называется по id буквы (`alphabet-1-he.png`), картинка сохраняется как `alphabet-1-he-example.webp`;
- проверки контента (`npm run validate:content`) запускаются перед сохранением.

Локально то же самое: положить файлы в `content/inbox/images`, выполнить `npm install --no-save sharp` и `npm run images:inbox` (с `-- --dry-run` покажет, что будет сделано, ничего не меняя).

## Лицензия

Берите только свои рисунки или картинки с лицензией, которая разрешает такое использование. Если лицензия требует указать автора (например CC BY), добавьте строку в `CREDITS.md`.
