# CLAUDE.md — Milav

Читай этот файл в начале каждой сессии. Язык общения и документации: **русский**. Владелец не разработчик: объяснять простыми словами, решения предлагать с вариантами.

## Что это

Telegram-мини-приложение (Mini App) для изучения иврита для русскоязычных. Бот `@milavbotbot`, адрес `https://milav.moshemadwords.workers.dev`. Продукт: `docs/SPEC.md`.

## Правила работы

- **Код правит Claude прямо в репозитории** (решение владельца 15.10: «важно, чтобы всё работало без ошибок»). Владелец код не копирует и не вставляет; в чат код выводится только по его просьбе. Каждая правка проходит `npm run check` и сквозные тесты до пуша. Прежнее правило «отдавать файлами целиком» относилось к копированию кода в чат и больше не нужно.
- Пушим **прямо в `main`**, коммиты маленькие и по одной теме. После пуша проверяем CI на GitHub и выкладку в Cloudflare (`gh api repos/mosheshanin/milav/commits/<sha>/check-runs`).
- Перед правкой читаем актуальный файл из репозитория, а не восстанавливаем его по памяти.
- Один чат — одна задача. В конце задачи: запись в `docs/CHANGELOG.md` (в конец), строка «Сейчас» и очередь задач ниже, новые вопросы в `docs/QUESTIONS.md`.
- Секреты (токен бота, ключи) только в `.env` / `.dev.vars` и в секретах Cloudflare и GitHub, в git они не попадают.
- Контент уроков живёт в `content/` как данные (JSON + схема + валидатор), а не в коде (`docs/CONTENT.md`).
- Дизайн-токены (цвета, радиусы, отступы, размеры иконок) в одном месте: `apps/web/src/index.css`. У каждого цвета интерфейса есть тёмное значение в `:root[data-theme="dark"]` (это проверяет тест `apps/api/src/theme-tokens.test.ts`); цвета напрямую в компонентах не пишем.
- Лимиты Cloudflare и Google перед решением проверяем по актуальной документации.
- Трейлеры коммитов: `Co-Authored-By` и `Claude-Session`, как требует среда.

## Архитектура (подтверждена владельцем)

Бесплатный хостинг без своего сервера: всё на Cloudflare.

| Слой | Решение |
|---|---|
| Приложение | Vite + React + TypeScript + Tailwind, Telegram WebApp SDK (`apps/web`); светлая и тёмная тема на токенах (`lib/theme.ts`) |
| Сервер | Cloudflare Worker (Hono), он же раздаёт собранное приложение (`apps/api`) |
| База | Cloudflare D1 (SQLite), миграции в `migrations/` |
| Аудио и картинки | файлы рядом с приложением (`apps/web/public/audio`, `words`); R2 позже (вопрос 30) |
| Вход | проверка подписи `initData` Telegram на сервере |
| Речь | Whisper в Workers AI |
| Журналы | Workers Logs (`docs/DEPLOY.md`, «Наблюдаемость») |
| Выкладка | Workers Builds: `npm run check`, миграции D1, деплой; CI в GitHub Actions со сквозными тестами |
| Бот | вебхук `POST /api/bot/webhook` на том же Worker, ответ в теле вебхука; вебхук регистрирует сам Worker |
| Панель | внутри приложения («Настройки» → «Панель администратора»), отдельный файл сборки; роли и настройки приложения в D1 (`apps/api/src/admin.ts`, `docs/ADMIN.md`) |
| Платежи | Telegram Stars (ещё не сделано) |

## Контент (решения владельца)

- Иерархия: раздел → тема (подраздел) → урок → слова. В уроке 10 слов.
- **В каждой теме первые 3 урока бесплатные, остальные платные**, независимо от общего количества уроков.
- Слова нужно подготовить заново: иврит, транскрипция кириллицей, перевод на русский, аудио.

## Принятые решения (владелец)

- **Озвучка.** Аудио генерируем один раз официальным TTS (голоса he-IL) и храним файлами (R2 или статика). Неофициальный Google Translate не используем.
- **Проверка произношения.** Запись звука (MediaRecorder), отправка в Worker, распознавание моделью (Whisper в Workers AI), сравнение с целевым словом с допуском.
- **Рукописный ввод.** Проверка **по буквам**: нарисованная буква сравнивается с набором шаблонов (несколько вариантов начертания на каждую букву) с допуском на погрешность рисунка. Старые шаблоны утеряны, поэтому нужны инструмент записи шаблонов и новый набор: 22 буквы + 5 конечных форм = 27 форм. Алгоритм сравнения (кандидат: распознаватели семейства $1/$P с ресемплингом штрихов) проверяем прототипом на реальных рисунках.
- **Разделы.** Существительные, Глаголы, Прилагательные. Темы как в прошлой версии (Животные, Еда, Цвета, Семья, Дом и мебель и др.).
- **Монетизация.** Бесплатно первые 3 урока в каждой теме. Остальное за Telegram Stars: 500 Stars на 3 месяца или 5000 Stars навсегда (разовые платежи со сроком доступа в базе).
- **Викторина.** 25 вопросов по уроку из 10 слов: 5 типов по 5 (слух→русский, иврит→русский, русский→иврит, произнести, написать по буквам). Подробно в `docs/SPEC.md`.
- **Статусы.** Шахматные фигуры по числу сданных уроков: Пешка до 5, Конь до 20, Слон до 50, Ладья до 100, Ферзь до 300, Король до 500.

- **Проходной балл:** 20 из 25. Ошибки показываются сразу. В вопросах на рукописный ввод 2 попытки на каждую букву, ошибка фиксируется только после двух неверных вводов.
- **Статусы:** границы включительно, повторные прохождения не считаются.
- **Очки:** за каждое слово, пройденное по всем 4 этапам (слушать, говорить, писать, печатать).
- **Карточка слова:** кроме печатного написания, транскрипции и перевода показываем рукописное начертание (рукописный шрифт), род слова и простую фразу-пример для запоминания рода.
- **Темы уроков и тема «Алфавит»** утверждены. В алфавите этапы: слушай, пиши, печатай (без «говори»).

## Решения по геймификации (владелец, 13.10 и 14.10)

Подробно: `docs/GAMIFICATION.md` (раздел 1.1 решения, 1.2 как реализовано).

- Механики: бейджи и экран «Достижения», недельный ритм (без заморозок), цель дня, итоги недели, сравнение с теми, кто пришёл в одно время, таблица лидеров (по согласию), праздничные листы и отклик устройства, «Поделиться». Друзей и командных целей нет. Награды только символические.
- Неделя начинается с **воскресенья**; неделя ритмична при 3 днях занятий; граница дня местная (пояс телефона, по умолчанию `Asia/Jerusalem`). Цель дня включена на 5 словах.
- Таблица: неделя и всё время, топ-20 показывается и тем, кто не участвует; имя из Telegram без фамилии и username; скрывшиеся места не видят; **потолка очков нет**; в проде включена (`LEADERBOARD_ENABLED = "1"`, 14.10, без отдельной политики конфиденциальности).
- Фраза о возрасте в согласии не нужна. Ссылка «Поделиться»: `https://t.me/milavbotbot`. Сравнение с ровесниками показывается и скрывшимся из таблицы (у них свой выключатель).
- Rate Limiting binding Cloudflare не используем (для бесплатного тарифа не подтверждён).

## Решения по глаголам (владелец, 14.10)

Задача 9. Подробный формат: `docs/CONTENT.md` (раздел «Глаголы»).

- **Модель слова.** `he` это инфинитив; блок `verb`: `binyan` (`paal`, `nifal`, `piel`, `hifil`, `hitpael`; пуаль и хуфъаль отдельным уроком позже), `root` (3–4 буквы, без конечных форм) и формы, у каждой `he`, `niqqud`, `translit`, `audio`. Род живёт в формах, поля `gender` и `forms` у глаголов остаются запрещены.
- **Набор форм: полная учебная таблица.** Настоящее `ms fs mp fp`; прошедшее `1s 2ms 2fs 3ms 3fs 1p 2mp 2fp 3p`; будущее `1s 2ms 2fs 3ms 3fs 1p 2mp 2fp 3mp 3fp`; повелительное `ms fs mp fp` (необязательно: у части глаголов его нет). До 27 форм на глагол.
- **Темы по бинъянам:** `paal`, `piel`, `hifil`, `nifal`, `hitpael` (topicId равен ключу бинъяна, в теме только его глаголы, это проверяет тест). Тематические темы со смешанными бинъянами добавим позже. Первые уроки только на сильных корнях; слабые корни (гзары) отдельной темой, для них понадобится поле `gizra` и своя проверка корня в формах.
- **Как учим (вариант B).** Карточка: плашка «бинъян · корень», вкладки времён, кнопки «послушать» у форм. Этапы и викторина по инфинитиву, как у остальных слов. Отдельный режим «Практика форм» после урока не влияет на сдачу урока, очки и статусы. Своя викторина по формам (вариант C) позже, отдельной задачей.
- **Озвучка: все формы**, файлы `/audio/<id слова>-form-<время>-<ключ>.mp3` (например `paal-1-write-form-past-3ms.mp3`), до 27 файлов на глагол, около 270 на урок.
- План: этап 1 типы, схема, правила, тесты (сделано 14.10); этап 2 карточка и озвучка форм; этап 3 «Практика форм»; этап 4 уроки «Пааль 1–3» (сильные корни), проверка носителем; этап 5 уроки «Пиэль 1–3» (сильные корни, сделано 15.10).

## Решения по админ-панели (владелец, 15.10)

Подробно: `docs/ADMIN.md` (раздел «Этап 1: как сделано»).

## Решения по шаблонам букв (владелец, 13.10)

- Хранение: рисунки пишутся в D1 как приёмник, в репозиторий попадают выгрузкой (`data/handwriting/own-strokes.json` и `ownTemplates.json`), источник истины файлы в git.
- Записывают администраторы (с 15.10, задача 4): вход из панели («Шаблоны букв») или по параметру запуска `startapp=record`, роль проверяет сервер.
- 5 вариантов на форму (135 рисунков). Рисунки обычных пользователей не собираем.
- Тариф Workers бесплатный (10 мс процессорного времени на запрос): распознавание ускорено, решения не меняются (тест эквивалентности с прямой реализацией).

## Решения по викторине (владелец, 12.10)

- Вопрос «произнеси»: 2 попытки (оставили).
- При 6-й ошибке викторина **прерывается** и ничего не сохраняется: состояние такое, как будто её не начинали.
- Запись на этапе «говори» идёт с эквалайзером в реальном времени и останавливается сама: после паузы 0,7 с после речи или через 2,5 с (константы `SPEAK_MAX_MS`, `SPEAK_SILENCE_MS`), можно и вручную. Логика паузы: `apps/web/src/lib/silence.ts` (с тестами); пороги подобраны без реальных голосов, при проблемах на телефонах пересмотреть.
- Микрофон: перед системным запросом показываем своё приглашение (зачем нужен доступ), при отказе инструкция по платформам (`lib/micHelp.ts`). Поток микрофона создаётся один раз и используется для всех записей, пока приложение открыто (`lib/mic.ts`), при сворачивании освобождается. Запомнить разрешение между запусками приложение само не может: это решает клиент Telegram (на части устройств запрос повторяется при каждом открытии).
- Озвучка: Google Cloud TTS, файлы создаются через GitHub Actions (`docs/AUDIO.md`), в синтезатор уходит слово с огласовками (`niqqud`); голос he-IL-Wavenet-A и вариант `niqqud` выбраны владельцем на слух (13.10).
- Проблемы с микрофоном или распознаванием: показываем сообщение с подсказкой и кнопкой «Попробовать снова». Слово без этапа «говори» не засчитывается.

## Как начать новый чат

Открыть чат в проекте «Milav» и написать: «Читай CLAUDE.md и сделай задачу N из “Следующих задач”». Claude клонирует `mosheshanin/milav`, делает задачу, проверяет, пушит в `main` и обновляет документы.
