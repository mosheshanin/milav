## Что это

Telegram-мини-приложение (Mini App) для изучения иврита. Подробности продукта: `docs/SPEC.md`.
Старый код утерян, проект перезапускается с нуля. Остались только дизайн-референсы в `design/`.

## Правила работы

- Код отдаётся **файлами целиком** (решение владельца), без фрагментов вида «остальное без изменений».
- Пушим **прямо в `main`**, коммиты маленькие и по одной теме.
- Перед правкой читаем актуальный файл из репозитория, а не восстанавливаем его по памяти.
- Один чат — одна задача. В конце задачи обновляем раздел «Статус» ниже.
- Секреты (токен бота, ключи) только в `.env` / `.dev.vars`, в git они не попадают. В репозитории лежит `.env.example`.
- Контент уроков живёт в `content/` как данные (JSON + схема + валидатор), а не в коде.
- Дизайн-токены (цвета, радиусы, отступы, размеры иконок) в одном файле, чтобы не повторялась проблема несогласованного стиля из прошлой версии.
- Трейлеры коммитов: добавляем `Co-Authored-By` и `Claude-Session`, как требует среда.

## Архитектура (предложена, подтвердить с владельцем)

Цель: бесплатный хостинг без своего сервера и без SSH.

| Слой | Решение |
|---|---|
| Фронтенд | Vite + React + TypeScript + Tailwind, Telegram WebApp SDK |
| Бэкенд | Cloudflare Workers (Hono), он же раздаёт статику фронтенда |
| База данных | Cloudflare D1 (SQLite): пользователи, прогресс, очки, покупки |
| Файлы (аудио) | Cloudflare R2 или статика рядом с приложением |
| Авторизация | Проверка подписи `initData` от Telegram на стороне Worker |
| Платежи | Telegram Stars (для цифровых товаров в мини-приложениях) |
| Бот | Webhook на Worker, кнопка меню открывает мини-приложение |

Альтернатива: Vercel + внешняя БД (Neon/Supabase). Выбрали Cloudflare, чтобы всё было на одной платформе. Точные лимиты бесплатного тарифа проверяем перед деплоем.

Планируемая структура:

```
apps/web/      мини-приложение (Vite + React + Tailwind)
apps/api/      Worker (Hono, D1), раздаёт и API, и собранный фронтенд
content/       уроки: schema.json, данные, скрипт-валидатор
design/        референсы (есть)
docs/          спецификация
```

## Контент (решения владельца)

- Иерархия: раздел → тема (подраздел) → урок → слова. В уроке 10 слов.
- **В каждой теме первые 3 урока бесплатные, остальные платные**, независимо от общего количества уроков.
- Слова нужно подготовить заново: иврит, транскрипция кириллицей, перевод на русский, аудио.

## Принятые решения (владелец)

- **Озвучка.** Аудио генерируем один раз официальным TTS (голоса he-IL) и храним файлами (R2 или статика). Неофициальный Google Translate не используем.
- **Проверка произношения.** Запись звука (MediaRecorder), отправка в Worker, распознавание моделью (Whisper в Workers AI), сравнение с целевым словом с допуском.
- **Рукописный ввод.** Проверка **по буквам**: нарисованная буква сравнивается с набором шаблонов (несколько вариантов начертания на каждую букву) с допуском на погрешность рисунка. Старые шаблоны утеряны, поэтому нужны инструмент записи шаблонов и новый набор: 22 буквы + 5 конечных форм = 27 форм. Алгоритм сравнения (кандидат: распознаватели семейства $1/$P с ресемплингом штрихов) проверяем прототипом на реальных рисунках.
- **Разделы.** Существительные, Глаголы, Прилагательные. Темы как в прошлой версии (Животные, Еда, Цвета, Семья, Дом и мебель и др.).
- **Монетизация.** Подписка (Telegram Stars). Бесплатно первые 3 урока в каждой теме, подписка открывает все остальные.
