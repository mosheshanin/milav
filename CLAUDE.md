# CLAUDE.md — Milav

Читай этот файл в начале каждой сессии. Язык общения и документации: **русский**. Владелец не разработчик: объяснять простыми словами, решения предлагать с вариантами.

## Что это

Telegram-мини-приложение (Mini App) для изучения иврита для русскоязычных. Бот `@milavbotbot`, адрес **`https://milav.app`** (свой домен с 19.11.2026, `APP_URL` в `wrangler.jsonc`; запасной `https://milav.moshemadwords.workers.dev` тоже работает, `docs/DEPLOY.md`, «Свой домен milav.app»). Продукт: `docs/SPEC.md`.

## Правила работы

- **Код правит Claude прямо в репозитории** (решение владельца 15.10: «важно, чтобы всё работало без ошибок»). Владелец код не копирует и не вставляет; в чат код выводится только по его просьбе. Каждая правка проходит `npm run check` и сквозные тесты до пуша. Прежнее правило «отдавать файлами целиком» относилось к копированию кода в чат и больше не нужно.
- Пушим **прямо в `main`**, коммиты маленькие и по одной теме. После пуша проверяем CI на GitHub и выкладку в Cloudflare (`gh api repos/mosheshanin/milav/commits/<sha>/check-runs`).
- Перед правкой читаем актуальный файл из репозитория, а не восстанавливаем его по памяти.
- Один чат — одна задача. В конце задачи: запись в `docs/CHANGELOG.md` (в конец), строка «Сейчас» и очередь задач ниже, новые вопросы в `docs/QUESTIONS.md`.
- Секреты (токен бота, ключи) только в `.env` / `.dev.vars` и в секретах Cloudflare и GitHub, в git они не попадают.
- Контент уроков живёт в `content/` как данные (JSON + схема + валидатор), а не в коде (`docs/CONTENT.md`).
- **Слов уроков в приложении нет:** приложение берёт `@milav/content/manifest` и `api.lesson()`, импорт `@milav/content` в `apps/web/src` запрещён (тест и проверка сборки `tools/check-bundle.mjs`). После правки урока: `npm run content:index`.
- Дизайн-токены (цвета, радиусы, отступы, размеры иконок, шкала мелкого текста) в одном месте: `apps/web/src/index.css`. У каждого цвета интерфейса есть тёмное значение в `:root[data-theme="dark"]` (это проверяет тест `apps/api/src/theme-tokens.test.ts`); цвета напрямую в компонентах не пишем.
- Лимиты Cloudflare и Google перед решением проверяем по актуальной документации. Расчёт нагрузки и вердикт по бесплатному тарифу: `docs/DEPLOY.md`, «Нагрузка и бесплатный тариф».
- **Сквозной тест в CI идёт группами одновременно** (24.11.2026, `tools/e2e-group.mjs`, около 10 минут вместо 42; `docs/DEPLOY.md`, «Сквозной тест в CI»). Репозиторий публичный, минуты GitHub бесплатны: **перед следующим пушем ждём только «Типы, тесты, сборка» и выкладку Cloudflare**, итог «Сквозной тест (итог)» проверяем в конце задачи (непроверенное не теряется: CI сравнивает с последним успешным прогоном). Если репозиторий снова станет закрытым, вернуть правило «ждать зелёного CI перед пушем» (лимит 2000 минут). Новый сквозной сценарий добавляется в `GROUPS` в `tools/e2e-group.mjs`, не шагом в `ci.yml`; тесты пишут в локальную базу через `tools/e2e-db.mjs`, не через `npx wrangler d1 execute`. Для новых уроков перед пушем достаточно `npm run check` и локального `E2E_LESSON=<id> node tools/e2e-lesson.mjs`.
- Трейлеры коммитов: `Co-Authored-By` и `Claude-Session`, как требует среда.

## Архитектура (подтверждена владельцем)

Бесплатный хостинг без своего сервера: всё на Cloudflare.

| Слой | Решение |
|---|---|
| Приложение | Vite + React + TypeScript + Tailwind, Telegram WebApp SDK (`apps/web`); светлая и тёмная тема на токенах (`lib/theme.ts`) |
| Сервер | Cloudflare Worker (Hono), он же раздаёт собранное приложение (`apps/api`) |
| База | Cloudflare D1 (SQLite), миграции в `migrations/` |
| Аудио и картинки | файлы рядом с приложением (`apps/web/public/audio`, `words`); к R2 возвращаемся при 15 000 файлов (24.11: 9237, предел бесплатного тарифа 20 000; вопрос 30) |
| Вход | проверка подписи `initData` Telegram на сервере |
| Речь | Whisper в Workers AI |
| Журналы | Workers Logs (`docs/DEPLOY.md`, «Наблюдаемость») |
| Выкладка | Workers Builds: `npm run check`, миграции D1, деплой; CI в GitHub Actions со сквозными тестами группами одновременно |
| Бот | вебхук `POST /api/bot/webhook` на том же Worker, ответ в теле вебхука; вебхук регистрирует сам Worker |
| Напоминания | таймер Durable Object раз в 10 минут (не cron: 5 расписаний на аккаунт), тексты в D1 (`apps/api/src/reminders.ts`, `scheduler.ts`) |
| Панель | внутри приложения («Настройки» → «Панель администратора»), отдельный файл сборки; роли и настройки приложения в D1 (`apps/api/src/admin.ts`, `docs/ADMIN.md`) |
| Платежи | нет: **платных тарифов не будет** (решение владельца 24.11, вопрос 48), все уроки бесплатны |

```
apps/web/        мини-приложение
apps/api/        Worker: API и раздача приложения
packages/shared/ правила продукта и общий код (константы, статусы, распознавание букв, глаголы, геймификация, журналы)
content/         уроки (lessons/*.json), схема, валидатор, правила, реестр (сервер), манифест без слов (приложение), генератор глаголов, ящик картинок
data/            исходные данные (штрихи шаблонов владельца, после записи)
migrations/      миграции D1
tools/           озвучка, картинки, шаблоны букв, отчёты по контенту, сквозные тесты (e2e-*.mjs)
.github/         CI, озвучка слов, картинки слов
design/          референсы
docs/            документация (ниже)
```

**Документы:** продукт `docs/SPEC.md`; контент (формат урока, транскрипция, как добавить урок) `docs/CONTENT.md`; деплой, проверки, лимиты, журналы `docs/DEPLOY.md`; озвучка `docs/AUDIO.md`; картинки `docs/IMAGES.md`; геймификация `docs/GAMIFICATION.md`; план улучшений и аудит `docs/ROADMAP.md`; админ-панель `docs/ADMIN.md` (этапы 1–3 сделаны); напоминания от бота `docs/REMINDERS.md` (этап 1 сделан); **открытые вопросы с постоянными номерами `docs/QUESTIONS.md`**; **история сделанного `docs/CHANGELOG.md`**; **ручные проверки на телефоне `docs/QA-PHONE.md`**. План наполнения контентом до 2000 слов (цель и разделы утверждены 24.11, вопросы 50 и 51; **таблица тем существительных утверждена 19.10**, добор около 130 существительных после волны 2 утверждён 24.11, вопрос 78): `docs/CONTENT-PLAN.md`.

## Контент (решения владельца)

- Иерархия: раздел → тема (подраздел) → урок → слова. В уроке 10 слов.
- **Все уроки бесплатны** (24.11, вопрос 48: платных тарифов не будет). Поле `free` в уроках и правило «бесплатен первый урок темы» (вопрос 52) остались в коде, но ни на что не влияют, пока `PAID_LESSONS_OPEN = true`; слово «платный» в документах значит «второй и дальше урок темы».
- Слова нужно подготовить заново: иврит, транскрипция кириллицей, перевод на русский, аудио.

## Принятые решения (владелец)

- **Озвучка.** Аудио генерируем один раз официальным TTS (голоса he-IL) и храним файлами (R2 или статика). Неофициальный Google Translate не используем.
- **Проверка произношения.** Запись звука (MediaRecorder), отправка в Worker, распознавание моделью (Whisper в Workers AI), сравнение с целевым словом **по звучанию**, соседние слова темы не засчитываются (18.10: `soundDistance` в `packages/shared/src/hebrew.ts`; фраза из нескольких слов целиком, один допуск на фразу, числа цифрами по `value`, 21.10; тихая א внутри слова, י/ו, ת/ט, ק/כ, א/ע прощаются, ה/א/ע на конце и ח настоящие; подробно `docs/SPEC.md`). Журнал `speech` пишет ожидаемое слово, расстояние, допуск и слово-соседа при отказе (`docs/DEPLOY.md`). Иврит латиницей (Whisper вернул «akhbar») разбирается на звуки и сравнивается (`latinSounds`, `latinDistance`; короткие слова с одной опорной согласной так не проверяются, вопрос 74). Подсказку Whisper (`initial_prompt`) не делаем (24.11, вопрос 73; вернуться, если верные слова часто не засчитываются); латиницу оставляем как есть (вопрос 74); отчёт по парам слов: `npm run speech:collisions`. **Голоса не слышно** (22.11, вопрос 136): на тишине Whisper выдумывает «תודה רבה»; тихую запись приложение не отправляет (один раз подряд), Whisper вырезает тишину (`vad_filter`), пустой ответ, «не речь» и фразы-галлюцинации дают `noSpeech` («Голоса не слышно», попытка не тратится; `isNoSpeech` в `apps/api/src/speech.ts`). Запись голоса не больше 150 КБ, битрейт 32 кбит/с (вопрос 91 решён 22.11).
- **Рукописный ввод.** Проверка **по буквам**: нарисованная буква сравнивается с набором шаблонов (несколько вариантов начертания на каждую букву) с допуском на погрешность рисунка. Старые шаблоны утеряны, поэтому нужны инструмент записи шаблонов и новый набор: 22 буквы + 5 конечных форм = 27 форм. Алгоритм сравнения (кандидат: распознаватели семейства $1/$P с ресемплингом штрихов) проверяем прототипом на реальных рисунках.
- **Разделы.** Существительные, Глаголы, Прилагательные. Темы как в прошлой версии (Животные, Еда, Цвета, Семья, Дом и мебель и др.).
- **Монетизация: нет** (решение владельца 24.11, вопрос 48). Все уроки бесплатны навсегда, Telegram Stars не делаем; `PAID_LESSONS_OPEN = true` в `packages/shared/src/constants.ts` остаётся. Прежний план (500 Stars на 3 месяца, 5000 навсегда) снят.
- **Викторина.** 25 вопросов по уроку из 10 слов: 5 типов по 5 (слух→русский, иврит→русский, русский→иврит, произнести, написать по буквам). Подробно в `docs/SPEC.md`.
- **Статусы.** Шахматные фигуры по числу сданных уроков: Пешка до 5, Конь до 20, Слон до 50, Ладья до 100, Ферзь до 300, Король до 500.

- **Общая викторина по всем буквам** (19.10): в «Алфавите» на главной, 28 вопросов по 27 буквам уроков 1–5 (без звуков дж, ж, ч), сдана при 22; **это не урок** (статус, сданные уроки, очки не меняет), за первую сдачу свой бейдж «Весь алфавит разом» (24.11, вопрос 75, миграция 0012), id `alphabet-all`, подробно `docs/SPEC.md`, «Тема «Алфавит»». Открывается, когда выучены все 27 букв.
- **Автопереход (19.10):** кнопка «Дальше» заливается 2 секунды и сама переводит дальше после **верного** ответа: на этапах урока, в викторинах (урока и общей), в повторении и «Практике форм»; после ошибки только по кнопке (`docs/SPEC.md`, «Автопереход в викторинах»).
- **Проходной балл:** 20 из 25. Ошибки показываются сразу. В вопросах на рукописный ввод 2 попытки на каждую букву, ошибка фиксируется только после двух неверных вводов.
- **Статусы:** границы включительно, повторные прохождения не считаются.
- **Очки:** за каждое слово, пройденное по всем 4 этапам (слушать, говорить, писать, печатать).
- **Слова из нескольких слов (21.10, вопрос 55):** `he` может быть фразой из 2–3 слов через пробел («אחר כך», «בית ספר», числа 11–19; `MAX_WORD_PARTS`). «Пиши»: все буквы подряд, пробел не рисуют, клетки группами по словам. «Печатай»: пробел не набирают, его ставит приложение. «Говори»: вся фраза, один допуск на фразу, запись до 4 с с паузой 1,2 с. У чисел поле `value`: ответ Whisper цифрами засчитывается. Подробно `docs/SPEC.md`, «Слова из нескольких слов», и `docs/CONTENT.md`.
- **Карточка слова:** кроме печатного написания, транскрипции и перевода показываем рукописное начертание (рукописный шрифт), род слова и простую фразу-пример для запоминания рода.
- **Род во фразах-примерах (22.10):** настройка «Фразы-примеры от лица» (мужчины по умолчанию / женщины, на сервере: `user_stats.gender`, миграция 0010). Фраза от первого лица, зависящая от рода говорящего, размечена `speaker: "m"` и женским вариантом `female` («אני הולך» / «אני הולכת», «Я устал» / «Я устала»); мужская озвучена мужским голосом (`-phrase-m.mp3`, `he-IL-Wavenet-B`, выбран без прослушивания, вопрос 131), женская женским (`-phrase-f.mp3`). Новые уроки размечает автор, правило набора краснеет при пропуске; генераторы глаголов размечают сами. Подробно `docs/CONTENT.md`, «Фразы от первого лица», `docs/SPEC.md`, `docs/AUDIO.md`.
- **Темы уроков и тема «Алфавит»** утверждены. В алфавите этапы: слушай, пиши, печатай (без «говори»).

## Решения по геймификации (владелец, 13.10 и 14.10)

Подробно: `docs/GAMIFICATION.md` (раздел 1.1 решения, 1.2 как реализовано).

- Механики: бейджи и экран «Достижения», недельный ритм (без заморозок), цель дня, итоги недели, сравнение с теми, кто пришёл в одно время, таблица лидеров (по согласию), праздничные листы и отклик устройства, «Поделиться». Друзей и командных целей нет. Награды только символические.
- Неделя начинается с **воскресенья**; неделя ритмична при 3 днях занятий; граница дня местная (пояс телефона, по умолчанию `Asia/Jerusalem`). Цель дня включена на 5 словах.
- Таблица: неделя и всё время, топ-20 показывается и тем, кто не участвует; имя из Telegram без фамилии и username; скрывшиеся места не видят; **потолка очков нет**; в проде включена (`LEADERBOARD_ENABLED = "1"`, 14.10, без отдельной политики конфиденциальности).
- Фраза о возрасте в согласии не нужна. Ссылка «Поделиться»: `https://t.me/milavbotbot`. Сравнение с ровесниками показывается и скрывшимся из таблицы (у них свой выключатель).
- Rate Limiting binding Cloudflare не используем (для бесплатного тарифа не подтверждён).

## Решения по глаголам (владелец, 14.10)

Задача 9. Подробный формат: `docs/CONTENT.md` (раздел «Глаголы»).

- **Модель слова.** `he` это инфинитив; блок `verb`: `binyan` (`paal`, `nifal`, `piel`, `hifil`, `hitpael`; пуаль и хуфъаль отдельным уроком позже), `root` (3–4 буквы, без конечных форм) и формы, у каждой `he`, `niqqud`, `translit`, `audio`. Род живёт в формах, поля `gender` и `forms` у глаголов остаются запрещены.
- **Набор форм: полная учебная таблица.** Настоящее `ms fs mp fp`; прошедшее `1s 2ms 2fs 3ms 3fs 1p 2mp 2fp 3p`; будущее `1s 2ms 2fs 3ms 3fs 1p 2mp 2fp 3mp 3fp`; повелительное `ms fs mp fp` (необязательно: у части глаголов его нет). До 27 форм на глагол.
- **Темы по бинъянам:** `paal`, `piel`, `hifil`, `nifal`, `hitpael` (topicId равен ключу бинъяна, в теме только его глаголы, это проверяет тест). Тематические темы со смешанными бинъянами добавим позже. Первые уроки только на сильных корнях; слабые корни (гзары) отдельной темой `weak` (18.10): поле `gizra` и своя проверка корня в формах уже есть.
- **Как учим (вариант B).** Карточка: плашка «бинъян · корень», вкладки времён, кнопки «послушать» у форм. Этапы и викторина по инфинитиву, как у остальных слов. Отдельный режим «Практика форм» после урока не влияет на сдачу урока, очки и статусы. Своя викторина по формам (вариант C) позже, отдельной задачей.
- **Озвучка: все формы**, файлы `/audio/<id слова>-form-<время>-<ключ>.mp3` (например `paal-1-write-form-past-3ms.mp3`), до 27 файлов на глагол, около 270 на урок.
- План: этап 1 типы, схема, правила, тесты (сделано 14.10); этап 2 карточка и озвучка форм; этап 3 «Практика форм»; этап 4 уроки «Пааль 1–3» (сильные корни), «Пааль 4» (гортанные корни, 19.10) и «Пааль 5» (патах в будущем и гортанная посередине, 19.10) и «Пааль 6» (частые глаголы, вторая א и немая шва под ח у לחתוך, 22.10), проверка носителем; этап 5 уроки «Пиэль 1–3» (сильные корни, сделано 15.10); этап 6 уроки «Хифъиль 1–3» (сильные корни, сделано 17.10); этап 7 уроки «Нифъаль 1–3» (сильные корни, сделано 18.10; «Практика форм» и повторение не считают одинаково звучащие формы разными: `formSound`); этап 8 уроки «Хитпаэль 1–3» (сильные корни, сделано 18.10: генератор `conjugateHitpael` с перестановкой ת у ס ש צ ז, второй ר и гортанными, слиянием третьей נ; повелительное оставлено у всех 30 глаголов; совпадающие целиком формы прошедшего 3ms и повелительного ms, 3p и mp в «Практике форм» и повторении тоже не спрашиваются).
- **Книжные формы** (17.10, вопрос 31): будущее 2fp и 3fp (תכתובנה) и повелительное fp на карточке с пометкой «книжн.», в «Практике форм» и в повторении не спрашиваются (`isBookForm`, `spokenVerbForms` в `packages/shared/src/verbs.ts`); в данных уроков остаются.

## Решения по викторине (владелец, 12.10)

- Вопрос «произнеси»: 2 попытки (оставили).
- При 6-й ошибке викторина **прерывается** и ничего не сохраняется: состояние такое, как будто её не начинали.
- Запись на этапе «говори» идёт с эквалайзером в реальном времени и останавливается сама: после паузы 0,7 с после речи или через 2,5 с (константы `SPEAK_MAX_MS`, `SPEAK_SILENCE_MS`), можно и вручную. Логика паузы: `apps/web/src/lib/silence.ts` (с тестами); пороги подобраны без реальных голосов, при проблемах на телефонах пересмотреть.
- Микрофон: перед системным запросом показываем своё приглашение (зачем нужен доступ), при отказе инструкция по платформам (`lib/micHelp.ts`). Поток микрофона и анализатор громкости создаются один раз, вместе, и используются для всех записей (`lib/mic.ts`); дорожку между записями **не выключаем** (на iPhone `enabled = false` убивает звук, 22.11, вопрос 138), звуковой движок запускается прямо по нажатию «Записать» (`primeAudio`); мёртвый поток (закончился, заглушён системой, ровный ноль за запись) приложение замечает и создаёт заново при следующем нажатии; микрофон отпускается через минуту без записей и при сворачивании. Запомнить разрешение между запусками приложение само не может: это решает клиент Telegram (на части устройств запрос повторяется при каждом открытии).
- Озвучка: Google Cloud TTS, файлы создаются через GitHub Actions (`docs/AUDIO.md`), в синтезатор уходит слово с огласовками (`niqqud`); голос he-IL-Wavenet-A и вариант `niqqud` выбраны владельцем на слух (13.10). Мужские фразы от первого лица (22.10) озвучивает he-IL-Wavenet-B (вход workflow `male_voice`).
- Проблемы с микрофоном или распознаванием: показываем сообщение с подсказкой и кнопкой «Попробовать снова». Слово без этапа «говори» не засчитывается.

Открыть чат в проекте «Milav» и написать: «Читай CLAUDE.md и сделай задачу N из “Следующих задач”». Claude клонирует `mosheshanin/milav`, делает задачу, проверяет, пушит в `main` и обновляет документы.
