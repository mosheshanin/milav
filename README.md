# Milav

Telegram-мини-приложение для изучения иврита для русскоязычных пользователей.

Каждое слово проходит четыре этапа: **слушай → говори → пиши → печатай**. После урока идёт квиз, за результат начисляются очки и растёт статус.

## Статус

Проект перезапускается с нуля. Старый код утерян, сохранились только дизайн-референсы (папка `design/`).
Текущий статус и план работ ведутся в [`CLAUDE.md`](./CLAUDE.md), описание продукта в [`docs/SPEC.md`](./docs/SPEC.md).

## Структура репозитория

```
design/        логотип, иллюстрации этапов, скриншоты старой карточки слова
docs/          спецификация продукта
CLAUDE.md      правила работы, архитектура, решения, статус
```

Папки с кодом (`apps/`, `content/`) появятся в процессе разработки.
