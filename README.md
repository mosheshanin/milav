# Milav

Telegram-мини-приложение для изучения иврита для русскоязычных пользователей.

Каждое слово проходит четыре этапа: **слушай → говори → пиши → печатай**. После урока идёт викторина на 25 вопросов, за каждое выученное слово начисляется очко, за сданные уроки растёт шахматный статус.

## Статус

Работает на Cloudflare (Worker + D1): вход через Telegram, 27 уроков (алфавит, существительные, прилагательные, глаголы пааль и пиэль), четыре этапа, викторина на сервере, очки, статусы, бейджи и таблица лидеров, журналы ошибок. Контент ещё не проверен носителем языка, платной подписки пока нет.
Решения владельца и очередь задач: [`CLAUDE.md`](./CLAUDE.md). История работ: [`docs/CHANGELOG.md`](./docs/CHANGELOG.md). Открытые вопросы: [`docs/QUESTIONS.md`](./docs/QUESTIONS.md). Описание продукта: [`docs/SPEC.md`](./docs/SPEC.md). Анализ и план улучшений: [`docs/ROADMAP.md`](./docs/ROADMAP.md).

## Структура репозитория

```
apps/web/        мини-приложение (React, Vite, Tailwind)
apps/api/        Worker (Hono, D1): API и раздача приложения
packages/shared/ правила продукта и общий код (константы, статусы, сравнение слов)
content/         уроки в JSON и тесты контента
migrations/      миграции базы D1
tools/           озвучка (Google TTS), стенд распознавания букв, сквозной тест в браузере
.github/         GitHub Actions: проверки (CI), озвучка слов, картинки слов
design/          логотип, иллюстрации этапов, скриншоты старой версии
docs/            SPEC (продукт), CONTENT (уроки), DEPLOY (деплой, проверки, журналы), AUDIO, IMAGES, GAMIFICATION, ROADMAP (план), QUESTIONS (открытые вопросы), CHANGELOG (история)
CLAUDE.md        правила работы, архитектура, решения владельца, очередь задач
CREDITS.md       лицензии картинок и шрифтов
```
