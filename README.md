# Milav

Telegram-мини-приложение для изучения иврита для русскоязычных пользователей.

Каждое слово проходит четыре этапа: **слушай → говори → пиши → печатай**. После урока идёт викторина на 25 вопросов, за каждое выученное слово начисляется очко, за сданные уроки растёт шахматный статус.

## Статус

Работает на Cloudflare (Worker + D1): вход через Telegram, один тестовый урок («Животные 1», 10 слов), четыре этапа, викторина, очки и статусы.
Подробный статус и решения владельца: [`CLAUDE.md`](./CLAUDE.md). Описание продукта: [`docs/SPEC.md`](./docs/SPEC.md). Анализ и план улучшений: [`docs/ROADMAP.md`](./docs/ROADMAP.md).

## Структура репозитория

```
apps/web/        мини-приложение (React, Vite, Tailwind)
apps/api/        Worker (Hono, D1): API и раздача приложения
packages/shared/ правила продукта и общий код (константы, статусы, сравнение слов)
content/         уроки в JSON и тесты контента
migrations/      миграции базы D1
tools/           озвучка (Google TTS), стенд распознавания букв, сквозной тест в браузере
.github/         GitHub Actions: озвучка слов
design/          логотип, иллюстрации этапов, скриншоты старой версии
docs/            SPEC (продукт), DEPLOY (деплой и проверки), AUDIO (озвучка), ROADMAP (план улучшений)
CLAUDE.md        правила работы, архитектура, решения, статус, очередь задач
CREDITS.md       лицензии картинок и шрифтов
```
